1. Project Overview

This project focuses on building a career-advising chatbot using only prompt engineering.
No datasets, no fine-tuning, no APIs — just prompt design and a small LLM model.

The chatbot provides:

Career suggestions based on user background

Skill and learning path recommendations

Resume improvement tips

Beginner-friendly guidance for engineering students

The model behaviour is tested before and after prompt optimization


2. Prompt Components Used
a. Role-Based Prompt

Defines the AI as a professional Career Advisor.

b. Instruction-Based Prompt

Explains what type of guidance the AI should give.

c. Few-Shot Examples

Shows sample questions and high-quality answers so the model learns the expected format.
